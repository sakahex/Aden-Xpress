# 🗺️ Geodata — for Auto route

## ⬇️ [Download Geodata_HighFive_L2J.zip](https://github.com/sakahex/Gludio-Gate/releases/download/geodata-hi5/Geodata_HighFive_L2J.zip)

*About 220 MB · Lineage 2 High Five · 203 map files (L2J format)*

---

The geodata is the game's map of where you can walk: ground, walls, bridges, stairs.
With it, the **Auto route** button on the route map finds a walkable way between your points by itself,
so you don't have to walk and record every route.

## How to use

1. Download the zip above and unzip it anywhere, e.g. `Desktop\Geodata`.
2. Gludio Gate → **Settings → App → Geodata folder** → pick that folder (the one with the `.l2j` files).
3. Open a route's **Map** → **Auto route**. Check it on the map and fix points by hand if you like.

Only the Gludio Gate editor reads these files — Adrenaline doesn't need them.
You do this once — updates keep your geodata folder.
